**Phantom Files Analytics** is a private tool used by the owner of the YouTube channels
幻影檔案 and Phantom Files. It reads those channels' own YouTube Analytics (views, watch time,
retention, traffic sources, impressions) so the owner can see which episodes work best, and
schedules the owner's own uploads.

It is not offered to anyone else. [Privacy policy](/phantom-files/privacy/)

幻影檔案 / Phantom Files 頻道主自用的工具：讀取自己頻道的 YouTube 數據、比較每集成效，並替自己上傳的影片設定排程。不對外提供。
