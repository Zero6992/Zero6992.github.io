**Phantom Files Analytics** is a private, read-only tool used by the owner of the YouTube channels
幻影檔案 and Phantom Files. It reads those channels' own YouTube Analytics (views, watch time,
retention, traffic sources, impressions) so the owner can see which episodes work best.

It is not offered to anyone else. [Privacy policy](/phantom-files/privacy/)

幻影檔案 / Phantom Files 頻道主自用的唯讀分析工具：讀取自己頻道的 YouTube 數據，比較每集的成效。不對外提供。
